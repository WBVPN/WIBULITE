# CARA DEPLOY / INSTALL WIBUVPN LITE (VERSI MENTAHAN / MASTER)

Versi ini adalah versi **MASTER MENTAHAN (UNENCRYPTED)**.
Semua file, termasuk `install.sh`, masih dalam bentuk source code asli (plaintext bash script) dan belum dienkripsi menggunakan SHC.

## 👨‍💻 1. INSTALL MANUAL (Oleh User)
Jika Bos ingin menginstal script mentahan ini ke VPS:
1. Login ke VPS menggunakan akses `root`.
2. Masuk ke direktori `WIBULITE` hasil ekstrak.
3. Jalankan perintah instalasi:
   `chmod +x install.sh && ./install.sh`

*(Catatan: Bos bebas mengedit `install.sh` sesuka hati sebelum menginstal, karena ini adalah source code murni!)*

## 🤖 2. DEPLOY OLEH AI (By AI)
Jika AI diminta memodifikasi atau menginstal script ini:
1. AI dapat mengedit `install.sh` atau file di dalam `menu/` dan `config/` terlebih dahulu jika diminta.
2. Setelah itu, AI dapat menjalankan `bash install.sh` untuk mengeksekusi instalasinya.
